# CF-Logics
A repository outlining our hybrid, human-in-the-loop approach for measuring CF institutional logics.
We have included the following documents to provide additional details about our emerging hybrid AI, human-in-the-loop workflow. First, we include a folder of Sample Annual Report PDFs containing a few community foundation annual reports for your reference. Our full corpus includes over 2,000 reports. Next, we provide the OCR script used to convert unstructured PDF report text into markdown files. The tagging script then translates individual names of people and community foundations into standardized entity tags. The report chunking script runs an NLP sentence splitter to parse text and regroups similar sentences using a cosine similarity threshold. The screen chunks regrex script then removes irrelevant chunks from analysis (e.g., lists of names or generic text such as "give today"). The script inference revised then runs the LLM labeling of CF logics. In this script, you can see how we translated our codebook into questions based on the elements we identified. 

If you download the human labeling interface html, you can see the interface we use for human labeling of report chunks. The sample human labeling folder contains sample output from the human labeling interface. In addition, we have also included the original human labeling completed at the start of our work along with a past presentation with more information about how this project has developed. The markdown file logic scoring and evaluation explains our emerging process of scoring the labeling output and comparing human and LLM labels.
